# نظام إدارة الإيجارات - تطبيق ويب

تطبيق ويب مبني باستخدام Streamlit لإدارة الإيجارات والمحلات التجارية.

## المميزات
- إدارة المستأجرين والعقارات
- العقود وجدولة الدفعات تلقائياً
- متابعة الدفعات وتسجيل السداد
- تقارير (كشف حساب، دفعات مستحقة، تقرير مناطق، إيرادات)
- ملاحظات وتنبيهات لكل مستأجر
